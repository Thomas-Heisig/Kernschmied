
# Kernschmied

Kernschmied ist eine lokal betreibbare, schema-gesteuerte KI-Chat- und Assistenzplattform (Backend: Python/FastAPI, Frontend: React/TypeScript).

Kurz: modulare Architektur, fokusiert auf offline-/intranet-fähigen Betrieb, Erweiterbarkeit und sichere Schnittstellen.

Status: MVP+ (laufende Entwicklung)

Schnellstart

- Voraussetzungen: Python 3.12, Node.js 20+, PowerShell (Windows)
- Entwicklung starten:

```powershell
.\start.ps1
```
