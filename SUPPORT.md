- .github/ISSUE_TEMPLATE/config.yml

Installation:

1. ZIP-Datei entpacken.
2. Den gesamten Inhalt in das Stammverzeichnis von F:\Kernschmied kopieren.
3. Vorhandene Dateien nur nach Prüfung überschreiben.
4. Änderungen kontrollieren:

   git status
   git diff

5. Danach committen:

   git add CONTRIBUTING.md CODE_OF_CONDUCT.md LICENSE CHANGELOG.md SECURITY.md SUPPORT.md .github
   git commit -m "docs: add community and repository files"
   git push
