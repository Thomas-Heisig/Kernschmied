# Hierarchie und Arbeitsbereiche

Die Hierarchie ist generisch aufgebaut. Sie kann Benutzer, Arbeitsbereiche, Projekte, Chats, Dokumente oder weitere freigegebene Knotentypen enthalten.

## Navigation

- Klicke auf einen Knoten, um ihn auszuwählen.
- Verwende den Pfeil, um untergeordnete Knoten ein- oder auszuklappen.
- Der Arbeitsbereich zeigt die für den Knotentyp registrierte Ansicht.

## Unbekannte Knotentypen

Ein unbekannter Typ wird nicht dynamisch ausgeführt. Die Oberfläche zeigt ihn kontrolliert als nicht unterstützt an.
